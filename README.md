 📝 Описание логики

Программа моделирует процесс ковки оружия. Пользователь вводит исходное качество стали (в процентах) и количество ударов молотом. 

Формула расчета:
1. Исходные примеси = 100 - Качество стали.
2. Каждый удар молотом снижает количество примесей на 15% от их *текущего* значения (экспоненциальное затухание).
3. Финальная прочность = 100 - Оставшиеся примеси.

На основе финальной прочности система автоматически присваивает предмету редкий грейд (от Обычного до Легендарного).
